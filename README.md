# Crowd Sourced Civic Issues Reporting And Resolution System

## Overview
The Crowd Sourced Civic Issues Reporting And Resolution System is a full-stack web application developed to help citizens report civic problems directly to municipal authorities. The platform improves communication between citizens and government departments by enabling online issue reporting, tracking, and management.

Citizens can submit complaints related to:
- Garbage issues
- Water leakage
- Road damage
- Drainage problems
- Streetlight failures
- Public sanitation issues

The system allows authorities to monitor complaints, update resolution status, and improve civic service efficiency.

---

## Features

### Citizen Module
- User Registration and Login
- Report Civic Issues
- Upload Complaint Images
- Track Complaint Status
- View Complaint History

### Admin Module
- Admin Authentication
- View All Complaints
- Update Complaint Status
- Manage Users
- Monitor Civic Issues
