# Crowd Sourced Civic Issues Reporting And Resolution System

## Overview
This project is a full-stack web application developed to help citizens report civic problems such as:
- Garbage issues
- Water leakage
- Road damage
- Streetlight failures

The system enables efficient communication between citizens and municipal authorities.

---

## Features
- User Registration and Login
- Issue Reporting with Image Upload
- Complaint Status Tracking
- Admin Dashboard
- Role-Based Access
- Real-Time Updates
- Responsive User Interface
